# Starlight V3

A local assistant for Windows 11 that does what you ask on your own PC. One native program:
you talk to it, it shows itself as a glowing orb on the screen, and a chat window comes second.
The model runs on your GPU. No account, no cloud.

Status: in development, not ready to use. See `PROGRESS.md` and the plan in `docs/plan.md`.
